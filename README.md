# MORROW COFFEE — Specialty Coffee Flagship Concept

Интерактивный концепт сайта современной спешелти-кофейни (**Interactive Website Concept / Digital Flagship Case Study**) на React, TypeScript, Tailwind CSS v4 и Framer Motion.

## Live Demo

* **Русская версия (по умолчанию, цены в ₽):** https://voiceeeeeee.github.io/morrow-coffee/?lang=ru
* **English version ($ pricing):** https://voiceeeeeee.github.io/morrow-coffee/?lang=en

## Features

* **Bilingual (`RU / EN`)** with header switcher, `?lang=ru` / `?lang=en` URL routing, and `localStorage` state persistence.
* **Interactive Menu & Cart:** category filters (`Coffee`, `Matcha`, `Cold Drinks`, `Desserts`), Full Menu modal with regular/decaf and milk modifiers, animated Cart Drawer with live total calculation, quantity controls, and toast notifications.
* **Editorial Storytelling:** full-bleed hero, asymmetric About narrative, interactive 5-frame Atmosphere gallery with Lightbox, Philosophy grid, Demo Reviews, interactive Neighborhood Map, and validated Contact Form.
* **Demo Mode Transparency:** order checkout and contact submissions run strictly in client-side demonstration mode without simulating live payments or backend storage.

## Stack

* React 19 + TypeScript + Vite 8
* Tailwind CSS v4
* Framer Motion & Lucide Icons

## Local Development

```bash
npm install
```
